# Social App

An Instagram-like social app with a Tinder-style Discover/matching feature and messaging between matches.

## Features

- 📸 **Feed** — Instagram-style feed with posts from matched users
- 🧭 **Discover** — Swipe right to like, swipe left to pass
- 💝 **Matches** — View all your matches and start conversations
- 💬 **Chat** — Message your matches in real-time
- 👤 **Profile** — View your profile and posts

## Tech Stack

- React 18 + TypeScript
- Vite + Tailwind CSS v4
- Supabase (auth + backend)
- React Router v7
- Motion (animations)
- Lucide React (icons)
- Sonner (toasts)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage

1. Create an account on the Signup page
2. Go to **Discover** to swipe on people
3. When you mutually like someone, they appear in **Matches**
4. Tap a match to start chatting in **Chat**
5. View your profile and posts on **Profile**
